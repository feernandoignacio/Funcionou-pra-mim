# Funcionou pra mim

Site de estudo com cartões de aprendizado, atividades para praticar e dicas, pensado para quem quer aprender de forma simples e organizada.

**Ver online:** https://feernandoignacio.github.io/Funcionou-pra-mim/

## O que tem no site

- **Início:** apresentação e o motivo do projeto
- **Cartões:** ferramentas úteis para facilitar o aprendizado
- **Estudar:** conteúdo organizado por dia e tema
- **Praticar e Atividades:** exercícios com correção e retorno imediato
- **Dicas:** orientações para estudar melhor
- **Login:** tela de acesso com validação de campos

## Tecnologias

- HTML5 e CSS3
- JavaScript (puro), organizado em componentes (`js/components`)
- `localStorage` para guardar dados no navegador

## Como rodar

Não precisa instalar nada. Baixe ou clone o repositório e abra o arquivo `index.html` no navegador.

```bash
git clone https://github.com/feernandoignacio/Funcionou-pra-mim.git
```
